vplayx - auto play 
===========================================================================

               ------------ getting started ------------

to get started:
  1. download the vplayx directory to your local machine
  2. Go to your browser extension settings and enable developer mode
      if it's not enabled
  3. On Chrome, click Unpack extension, then select the vplayx directory
  4. On Firefox, click Debug Extensions, then select the manifest file in
      in the vplayx directory
  5. You are done and can now use it

For more information, check:
                    vplayx/content.js
